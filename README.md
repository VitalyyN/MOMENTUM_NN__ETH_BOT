# Momentum60 NN Bot

Робот строит один сигнал в сутки по Bybit Spot ETHUSDT. MOMENTUM60 определяет направление, пять MLP оценивают неблагоприятное движение за пять суток. Торговля разрешена при трёх голосах из пяти. Цель составляет 40% equity в ETHUSDT USDT Perpetual. Защитный биржевой SL установлен на расстоянии 20% от первоначального исполнения. При изменении количества цена стопа сохраняется.

## Установка на Windows

Установите Python 3.13 x64. В корне клона скопируйте `.env.example` в `.env`. Укажите Telegram-токен, ID приватного чата и ID владельца. Для выбранной среды заполните её пару API-ключей. Храните ключи на выделенном счёте и ограничьте доступ к `.env` в Windows.

**Дважды щёлкните `start.bat` в Проводнике.** При первом запуске скрипт создаст `.venv` и установит зависимости. Робот запустится в видимом окне и будет ждать `Start_bot` в Telegram. Если запуск завершится ошибкой, окно останется открытым.

ONNX Runtime выполняет модели через готовые DLL. Если импорт `onnxruntime` выдаёт ошибку загрузки DLL, проверьте наличие Microsoft Visual C++ Redistributable x64. Если команда `check` проходит, на этой машине уже есть необходимые библиотеки. [Требования ONNX Runtime](https://onnxruntime.ai/docs/install/#requirements) · [Загрузка Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)

`DEMO = True` в `settings.py` выбирает Bybit Demo, `DEMO = False` выбирает реальный счёт. Флаг считывается при запуске. Подготовьте ETHUSDT в режиме one-way с плечом 1×. Для каждого режима свой SQLite и префикс уведомлений. Для перехода с закрытием текущей позиции сначала выполните `Stop_&_Close`, дождитесь подтверждения и остановите процесс.

```powershell
.\start.bat check
.\start.bat preview
.\start.bat console
```

`check` загружает все ONNX и проверяет контрольные прогнозы. `preview` вычисляет сигнал из публичных данных, а при наличии ключей читает баланс и показывает объём. Оба режима обходятся без торговых запросов.

Для фонового запуска выполните `.\start.bat install-task` из PowerShell с правами администратора. Задание `Momentum60_NN_bot` стартует при загрузке Windows от SYSTEM. Для первого запуска выберите «Выполнить» в Планировщике. Состояние, журналы и Python должны быть доступны SYSTEM. Файлы запуска привязаны к корню клона. Дневные логи пишутся в `logs/demo/` или `logs/live/`.

## Управление и восстановление

- `Start_bot` разрешает следующее своевременное решение после сверки. Робот присылает уведомление при запуске и ожидает эту команду. Нажатие после 01:00 UTC позволяет дождаться нового дневного сигнала.
- `Stop_&_Save` и `Ctrl+C` ставят торговлю на паузу и сохраняют позицию под SL. `Stop_&_Close` закрывает текущую подтверждённую позицию и сообщает о нулевом остатке.
- `Status` показывает позицию, первоначальный вход, SL, решение, голоса, срок моделей и заявку на сверке. `Balance` показывает equity. `PnL` суммирует биржевые операции с первого запуска журнала и выводит комиссию, полученный и уплаченный фандинг, открытый и чистый реализованный PnL.
- Когда включённая стратегия не получила решение к 01:00 UTC, она запрашивает закрытие и ждёт следующего дня. После аварии подтверждает отправленные заявки по бирже. При неопознанной позиции или заявке сообщает расхождение. Сохраните SQLite при переносе работающего робота. При смене ключа сверяйте состояние со счётом до переноса журнала.

## Модели и Git

В `models/current/` хранится один проверенный комплект. Начальные модели действуют с 01.11.2026 по 01.12.2026 00:00 UTC, правая граница исключается. Месячное дообучение выполняется на основном ПК из весов и состояния Adam прошлого месяца. Подробнее в журнале дипломного проекта.

На основном ПК установите `onnx` и `onnxruntime` в среду с PyTorch и запустите экспорт. Укажите исходный каталог `robot_bundle` и для расширенной сверки последовательные CSV часовых свечей.

```powershell
python -B export_models.py <путь-к-robot_bundle> --history <hourly.csv>
```

Экспорт сверяет прогнозы и голоса с PyTorch, сохраняет прежний комплект локально в `архив/` и заменяет `models/current/`. Публикуйте все файлы модели одним коммитом. После `git pull` на сервере робот проверяет SHA-256 и контрольные прогнозы перед применением комплекта. Журналы счёта, секреты и архив исключены из Git.

```powershell
.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

Тесты выполняются с имитацией исполнения и проверяют реальный локальный клиент `pybit` без отправки заявок.
